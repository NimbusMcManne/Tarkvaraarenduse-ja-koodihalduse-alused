# Tarkvaraarenduse-ja-koodihalduse-alused
Repositoorium, mis sisaldab __Tarkvaraarenduse ja koodihalduse alused__ kodutöid ning muid kursuse läbimiseks vajalikke andmeid/töid.

## Kodutöö 1:
Luua antud repositoorium koos README.md ja litsensiga. MIT litsents lubab selles repositooriumis olevat koodi kasutada, muuta, lisada, jagada ja kopeerida nii nagu keegi heaks arvab. Kuna tegemist on kodutöö repositooriumiga, siis pole sellel erilisit vahet millisedi muudatusi siia tehakse.
